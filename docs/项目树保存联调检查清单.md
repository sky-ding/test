# 项目树保存联调检查清单

## 范围

验证登录后的关系型项目树在项目阶段状态、部门项目人力登记、项目风险登记三页之间一致保存和回显。

## 前置条件

- 后端服务运行在 `http://127.0.0.1:8001`。
- 使用管理员账号登录。
- 浏览器打开 `frontend/index.html` 或后端静态页面。

## 检查步骤

1. 在项目阶段状态页新增项目集 `稳定性项目集`。
2. 将默认子项目集重命名为 `容灾子项目集`。
3. 将默认子项目重命名为 `商城容灾子项目`。
4. 在阶段页为该子项目录入任意阶段字段并保存。
5. 刷新页面，确认项目树和阶段字段仍然存在。
6. 切换到部门项目人力登记页，确认同一项目树已出现。
7. 新增或确认人力部门分组和二级列，录入该子项目的人力值并保存。
8. 刷新页面，确认项目树、人力部门表头和人力值仍然存在。
9. 切换到项目风险登记页，新增一条风险并保存。
10. 确认没有出现“设置页创建项目树”相关提示。
11. 刷新页面，确认风险记录仍然存在，并能关联到真实子项目。

## 失败信息采集

- 记录浏览器弹窗文案。
- 记录 Network 中失败接口的 URL、HTTP 状态码、响应体。
- 记录后端终端中的异常堆栈或错误日志。
