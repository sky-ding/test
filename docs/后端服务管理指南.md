## 📋 快速操作

### 检查后端服务状态

```bash
# 查看 Python 进程
ps aux | grep -E "uvicorn|fastapi" | grep -v grep

# 查看端口占用（8001 或 8080）
netstat -tlnp | grep -E "8001|8080"
# 或
ss -tlnp | grep -E "8001|8080"
```

## 🔴 关闭后端服务

### 方法 1：直接杀掉进程

```bash
# 查找 uvicorn 进程
ps aux | grep uvicorn | grep -v grep

# 杀掉进程（替换 <PID> 为实际进程 ID）
kill <PID>

# 如果进程不响应，强制杀掉
kill -9 <PID>
```

### 方法 2：使用 pkill

```bash
# 杀掉所有 uvicorn 进程
pkill -f uvicorn

# 或杀掉特定端口的进程
pkill -f "uvicorn.*8001"
pkill -f "uvicorn.*8080"
```

### 方法 3：如果在 screen/tmux 中运行

```bash
# 列出 screen 会话
screen -ls

# 进入会话（替换 <session_name>）
screen -r <session_name>

# 按 Ctrl+C 停止服务
# 或输入 exit 退出
```

### 方法 4：如果是 systemd 服务

```bash
# 停止服务
sudo systemctl stop ipd-pmo-backend

# 禁用开机自启
sudo systemctl disable ipd-pmo-backend

# 查看状态
sudo systemctl status ipd-pmo-backend
```

### 方法 5：如果是 Docker 容器

```bash
# 查看运行中的容器
docker ps | grep ipd-pmo

# 停止容器
docker stop <container_id>

# 或删除容器
docker rm -f <container_id>
```

## 🟢 启动后端服务

### 开发模式（本地测试）

```bash
cd /root/.openclaw/workspace/agent:main:uuid-mwrqpi65xxmpch8ped/test/backend

source .venv/bin/activate  # Linux/Mac
```

## 📊 服务管理脚本

### 创建管理脚本（可选）

```bash
#!/bin/bash
# save as: /root/.openclaw/workspace/agent:main:uuid-mwrqpi65xxmpch8ped/test/backend/manage.sh

BACKEND_DIR="/root/.openclaw/workspace/agent:main:uuid-mwrqpi65xxmpch8ped/test/backend"
PID_FILE="$BACKEND_DIR/uvicorn.pid"
LOG_FILE="$BACKEND_DIR/uvicorn.log"

case "$1" in
  start)
    cd "$BACKEND_DIR"
    source .venv/bin/activate
    nohup python -m uvicorn app.main:app --host 127.0.0.1 --port 8001 > "$LOG_FILE" 2>&1 &
    echo $! > "$PID_FILE"
    echo "Backend started on port 8001 (PID: $(cat $PID_FILE))"
    ;;
  
  stop)
    if [ -f "$PID_FILE" ]; then
      kill $(cat "$PID_FILE")
      rm "$PID_FILE"
      echo "Backend stopped"
    else
      pkill -f "uvicorn.*8001"
      echo "Backend processes killed"
    fi
    ;;
  
  restart)
    $0 stop
    sleep 2
    $0 start
    ;;
  
  status)
    if pgrep -f "uvicorn.*8001" > /dev/null; then
      echo "Backend is running"
      pgrep -f "uvicorn.*8001"
    else
      echo "Backend is not running"
    fi
    ;;
  
  *)
    echo "Usage: $0 {start|stop|restart|status}"
    exit 1
    ;;
esac
```

**使用：**
```bash
chmod +x manage.sh
./manage.sh start    # 启动
./manage.sh stop     # 关闭
./manage.sh restart  # 重启
./manage.sh status   # 查看状态
```

## 🛡️ 安全注意事项

1. **生产环境**不要使用 `--reload` 参数
2. **会话密钥** `PM_SESSION_SECRET` 必须自定义
3. **数据库密码**不要提交到代码库
4. **定期备份**数据库数据
5. **监控日志**文件，及时发现异常

## 📞 常见问题

### Q: 关闭服务后数据会丢失吗？
A: 不会。数据存储在数据库中（SQLite 或 MySQL），关闭服务不会影响已保存的数据。

### Q: 如何确认服务已完全关闭？
A: 使用 `ps aux | grep uvicorn` 查看是否还有进程，使用 `netstat -tlnp | grep 8001` 查看端口是否释放。

### Q: 服务关闭后前端还能访问吗？
A: 前端页面可以打开，但所有需要后端 API 的功能（保存、编辑等）将无法使用。

### Q: 重启服务需要多久？
A: 通常几秒钟即可启动完成。首次启动可能需要更长时间（数据库连接、表创建等）。
